# Развёртывание базы
Установите Microsoft SQL Server Express LocalDB 2022 или подготовьте экземпляр SQL Server с доступом через проверку подлинности Windows. Для первого запуска нужны права создать базу TourCraft и её таблицы.

В Windows PowerShell из корня проекта выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\database\Initialize-Database.ps1
```

Для другого экземпляра передайте параметр `-Server '.\SQLEXPRESS'`. В SSMS эквивалентный порядок — открыть по очереди `schema.sql` и `seed.sql` в подключении к выбранному экземпляру и выполнить целиком. Скрипты предназначены для первоначального развёртывания. Повторное создание существующих таблиц завершится ошибкой. Если схема уже создана, а наполнение прервалось, выполните только `seed.sql` в пустой схеме.

Признак успеха — в базе шесть таблиц, два маршрута, три отправления, одна бронь и один платёж. Для обычной работы приложению нужны чтение и изменение данных. Настройка подключения описана в основном README.
